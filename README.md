# Machine Learning for Cybersecurity Lab

This repository contains implementations of machine learning and
time-series techniques for cybersecurity applications.

## Experiments

### Experiment 1 - Time Series Decomposition
Identification of trend, seasonal and residual components in network traffic.

### Experiment 2 - Time Series Forecasting
ARIMA-based forecasting of historical network traffic for potential DDoS detection.

### Experiment 3 - Ensemble Learning
Random Forest classification of cyber-attacks.

### Experiment 4 - Logistic Regression
Classification of URLs as legitimate or phishing.

### Experiment 5 - Support Vector Machine
Classification of URLs as legitimate or phishing using SVM.

### Experiment 6 - URL Anomaly Detection
Feature engineering and Isolation Forest for detecting abnormal URL patterns.
